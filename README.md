# zafmy.github.io

Personal resume site for **Mohamad Zafir bin Nadzri** — live at [zafmy.github.io](https://zafmy.github.io).

## Structure

- `index.html` — single-file resume page (HTML + CSS, no build step)
- `images/profile.png` — profile photo used in the header
- `Mohamad-Zafir-Resume.docx` — downloadable Word version

## Local preview

Just open `index.html` in a browser, or serve it:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy

Pushed to the `main` branch of `zafmy/zafmy.github.io`; GitHub Pages serves it automatically at <https://zafmy.github.io>.
